## Decision

The comparison is against observable Windows security and lifecycle semantics, not Codex's Rust
module layout or implementation. Neuro Code uses Python `ctypes` and its existing
application/infrastructure boundaries to implement the same class of contract; model-controlled
process creation remains confined to the canonical sandbox adapter.

| Subsystem | Current Codex semantics | Current Neuro Code implementation | Result |
| --- | --- | --- | --- |
| identity / setup | dedicated identities, DPAPI credentials, elevated setup, Offline/Online selection | `windows_sandbox_setup.py`, `windows_sandbox_identity.py`, DPAPI store, W2 READY inspection | Semantically aligned; different language |
| restricted token | `DISABLE_MAX_PRIVILEGE`, `LUA_TOKEN`, `WRITE_RESTRICTED`; ordered capability, extra identity, Logon SID, and World SID set | W3 uses the same four-entry production set and attests `TokenUser`, restricted SIDs, `SeChangeNotifyPrivilege`, and unexpected privileges | Aligned |
| default DACL / ACL | bounded default DACL for child-owned IPC plus ACL/deny-read filesystem authority | `TokenDefaultDacl`, managed capability ACEs, sibling boundary denies, sensitive-path protection | Semantically aligned; explicit World-SID boundary deny is Neuro's adaptation |
| process boundary | `CreateProcessWithLogonW` → restricted token → `CreateProcessAsUserW`; attributes atomically add Job/handles/PTY | trusted runner, `CreateProcessAsUserW`, Job/handle-list or PTY/Job attribute list | Aligned |
| descendant lifecycle | Job ownership established at creation, kill-on-close, failure cleanup | `WindowsJobObject` plus `PROC_THREAD_ATTRIBUTE_JOB_LIST`, controller-loss fail-closed, state-based quiescence | Aligned |
| controller IPC | controller-owned named pipes, framed protocol, bounded connect/timeout/cleanup | random directional named pipes, exact DACLs, version/length frames, bounded relays | Aligned |
| ConPTY | `CreatePseudoConsole` and `PSEUDOCONSOLE` attribute; PTY does not inherit arbitrary handles | same attribute-list composition, raw-byte PTY output, resize frames, no arbitrary PTY handle inheritance | Aligned |
| network | persistent native WFP provider/filter scoped to the sandbox identity | W2 installs a persistent `New-NetFirewallRule -LocalUser <SID>` Offline deny; runtime only checks READY and never mutates | Behavioral semantics aligned; intentional API difference |
| environment / provenance | explicit runner/child environment and trusted code outside writable roots | `-I`, explicit allowlist, private HOME/TMP, interpreter/package/module disjointness checks | Aligned |
| credential failure | one credential-refresh retry for selected logon/startup errors | runtime reads authoritative DPAPI credentials; fails closed without runtime repair/UAC | Intentionally narrower; no security weakening |
| AppContainer | not the sole production prerequisite; capability is defined by token/ACL/runtime path | PR #48 AppContainer feasibility remains frozen and is not a production dependency | Consistent with the decision |

Codex's native WFP API and Neuro's Windows Firewall cmdlet are not API-for-API equivalent. The
acceptance contract is the Offline identity scope, persistence, exact rule inspection, no Online
mutation, and real `WSAEACCES` behavior. If a future environment requires bypassing managed
PowerShell policy, a native WFP helper can be evaluated independently; runtime fallback or a global
firewall rule is not an acceptable workaround.

## Acceptance boundary

- This audit does not treat HTTP 200, an occasional `partial`, or unit tests alone as Windows
  enforcement evidence.
- The final production decision must be regenerated by Windows native token, filesystem, network,
  Job, pipe, ConPTY, child/grandchild, and W5 workload jobs; local Linux runs can validate only
  static and cross-platform portions.
- `docs/windows-sandbox-implementation-ledger.md` is the concise source of current validation
  state. CI run `32374860136` validates the audited source head; the final branch update is
  evidence-only documentation and remains covered by the PR checks.
