# ADR 0041：只读技能正文加载工具

**简体中文** · [English](../../en/adr/0041-skill-body-loading-tool.md)

- 状态：已接受
- 日期：2026-07-22

## 背景

ADR 0040 只展示精简技能元数据；模型还需要一种显式方式，仅在技能相关时加载所选
工作流正文。

## 决策

注册无副作用的 `skill` 工具。它通过绑定的 `SkillContextTracker`，按去重后的技能名
查找技能；根据技能所属的 LOCAL、REPO 或 USER 根校验规范化相对路径，并执行共享的
有界、抗符号链接读取。

加载字节必须仍与发现时的内容指纹一致。若文件在发现与加载之间变化，工具返回可重试
错误，避免把旧元数据与新正文混合。工具验证 UTF-8 和控制字符，剥离 BOM 与
frontmatter，然后返回有界的 `<skill_content>` 块。

输出包含基础目录及最多 10 个直属常规文件名。捆绑链接、目录、含控制字符的名称，
以及超过 256 条目上限的目录会被省略；该列表不会读取或执行任何捆绑文件。

## 影响

- 工具输出遵守 `ToolContext.output_byte_limit`；超限会失败，不会静默截断。
- `ToolContext` 依赖追踪器端口，保持端口层到运行时层的正确依赖方向。
- 正文可能引导模型请求其他工具，但其他工具仍执行正常的权限和沙箱检查。
- ADR 0045 在此加载路径上增加有界参数替换。
