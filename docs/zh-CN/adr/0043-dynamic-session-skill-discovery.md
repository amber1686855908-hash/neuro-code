# ADR 0043：动态会话技能发现

**简体中文** · [English](../../en/adr/0043-dynamic-session-skill-discovery.md)

- 状态：已接受
- 日期：2026-07-22

## 背景

只扫描根目录会漏掉为项目嵌套区域定义的技能。Rust 基线会在会话中根据文件系统工具
访问的路径发现附近技能。

## 决策

每个绑定使用一个带单一移动目标的 `SkillTracker`。`read_file`、`list_dir` 和
`grep` 把目标移到访问目录；grep 完成阻塞遍历后，回到事件循环线程再更新状态。
下一模型步骤前，发现从目标向上遍历到工作区根，按深到浅处理。同名深层技能因此覆盖
浅层技能；移动到兄弟子树后，前一子树的技能会移出上下文。

所有 LOCAL 路径共用工作区根，并保留完整嵌套前缀，例如
`src/api/.neuro/skills/review/SKILL.md`。这避免兄弟子树间的路径歧义和指纹碰撞。
祖先遍历有上限；超限时中间层级被省略并记录拒绝，但仍扫描工作区根默认技能。

## 影响

- 新增、删除、正文变化和目标变化都在下一模型步骤生效，无需重启会话。
- `search_replace` 不移动技能目标，因为技能是指导而不是写入授权；Bash 路径仍有意不解析。
- 单目标策略保持上下文聚焦，但不会合并同一步访问的多个兄弟路径技能。
