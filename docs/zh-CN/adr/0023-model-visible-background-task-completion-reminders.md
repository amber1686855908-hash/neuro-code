# ADR 0023：在明确的模型边界报告后台任务完成状态

**简体中文** · [English](../../en/adr/0023-model-visible-background-task-completion-reminders.md)

- 状态：已接受
- 日期：2026-07-18
- 源代码基线：`c68e39f60462f28d9be5e683d9cbe2c57b1a5027`

## 背景

ADR 0022 让使用 TUI 的人可以看到会话作用域后台任务，但模型仍需轮询 `task_output` 才能
发现自然完成。固定 Rust 基线有三个相关表面：附加到后续工具结果的完成提醒、轮次间提醒，
以及可选自动唤醒轮次。阻塞任务输出/多任务等待结果或显式终止已经把终态告知模型，因此
基线会抑制对应的重复提醒。

无限制的自动唤醒会在没有新用户输入时启动新的付费模型轮次，并需要排队、取消和费用
控制。因此策略提供持久的用户级默认值，以及每个受管供应商配置的可选覆盖；新旧配置默认
都关闭。当前实现还提供会话级 `/auto-wake on|off` 覆盖，在 TUI 打开期间优先于持久设置。
把合成提醒作为普通会话消息持久化也不安全：本地任务记录不能跨重启存在，回放旧指针会
制造过期模型上下文。
因此调度器只为每个会话持久化有界的唤醒账本；不会保存命令文本、工作目录、输出、凭据或
伪造的任务快照。

## 决策

每个会话作用域 `BackgroundTaskManager` 都记录终态任务是否已向模型报告，并提供待报告
终态快照及幂等确认操作。`task_output` 和 `wait_tasks` 返回终态快照前会确认对应任务，
`kill_task` 也会确认结果，因此下一模型步骤不会重复工具结果中已经存在的信息。

每次明确模型步骤之前，`AgentRuntime` 读取当前作用域的待报告完成项，并以仅供模型使用的
user-role 运行时通知注入最多 20 条。每条记录都经过 JSON 转义，只包含任务 ID、状态、
退出码、输出总字节数及预览是否截断；命令文本和工作目录一律排除。普通用户回合仍只注入
元数据。明确的后台自动唤醒还可以附带脱敏后的输出预览，每个任务最多 2 KiB、每批提醒最多
8 KiB。预览会明确标记为不可信证据而不是用户意图；仅当 `task_output` 工具存在时才提示
使用它。超出批次的记录留到后续模型边界。

提醒只进入当前运行的供应商上下文，不加入 `SessionItem`、返回消息历史或 SQLite 会话项。
审计流会保留一个仅含元数据的 `background_task_completion_reminder` 事件。只有供应商产生
有效完成事件后，管理器才确认该批次；如果流式调用在此之前失败，后续重试仍可报告同一批，
不会丢失。

默认情况下系统不会自主创建轮次。工具执行期间完成的任务可在同一轮的下一模型步骤报告；
空闲 TUI 会话可以使用 `/auto-wake on` 显式启用，仅针对当前待处理完成批次启动一次仅供模型
使用的唤醒轮次，并且不会在另一轮运行时启动。只有模型有效完成后才消费完成提醒，唤醒使用的
合成提醒和助手回答不会进入持久会话项。`/auto-wake off` 可以在当前会话再次关闭该策略。
Settings 可以修改持久的全局默认值，供应商配置页还可以选择继承、启用或禁用覆盖。策略关闭时，
现有 TUI 轮询仍只负责展示。每次会话唤醒会先持久化进行中标记；只有成功完成的唤醒才会消费
待处理 ID 和一个有界会话预算单位，失败或取消的唤醒会保留 ID，只应用冷却时间。应用重启时会
清除进行中标记，并在启动后根据任务监管器的未报告终态任务重新核对待处理 ID；只有真实任务
仍存在且预算允许时，中断的唤醒才可以重试。

## 影响

- 模型无需反复轮询即可获知自然完成，同时任务作用域和应用进程所有权保持不变。
- 阻塞输出/多任务读取和显式终止只有一个规范模型结果，不会再生成重复提醒。
- 提醒大小和内容不受命令/输出大小影响且始终有界；命令、工作目录和凭据不能经此状态路径
  进入模型。自动唤醒的输出预览会脱敏、有界且只存在于临时上下文。
- 供应商失败不会消费尚未看到的完成项，成功模型步骤则会精确确认一次。
- 合成状态刻意不进入持久会话回放；持久审计事件会记录曾尝试注入。
- 完整输出文件和跨进程任务恢复仍是后续切片。前台自动转后台使用同一个内存任务记录，因而
  遵循这些完成提醒规则；持久唤醒账本刻意不替代存活的进程树或任务结果；重新核对时找不到
  的任务 ID 会被丢弃。多任务等待由 [ADR 0024](0024-event-driven-multi-background-task-wait.md)
  独立定义。

源证据来自固定提交中的历史 `TaskCompletionReminder`、已报告完成状态、轮次间排空，以及
阻塞等待/显式终止抑制行为。
