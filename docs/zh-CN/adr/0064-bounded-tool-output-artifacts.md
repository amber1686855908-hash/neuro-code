# ADR 0064：有界且脱敏的工具输出文件

[English](../../en/adr/0064-bounded-tool-output-artifacts.md) · **简体中文**

- 状态：已接受
- 日期：2026-08-06

## 背景

工具结果在跨越模型和 UI 边界前会被有意限制大小。这样可以保护上下文大小，
避免回放无界命令输出，但当长时间运行的本地命令预览被截断后，用户很难继续
检查完整结果。同时，既有进程、工作区、权限和脱敏边界必须继续拥有最终约束力。

## 决策

应用通过 `ToolContext` 注入可选的 `ToolOutputArtifactStore`。生产组合使用位于
配置应用状态目录下的文件适配器。适配器创建私有目录和文件，先写临时文件再用
`os.replace` 原子替换；在按字节截断前先脱敏配置凭据和常见凭据形状；每个文件最多
保留 8 MiB。

只有实际发生预览截断的本地 `BashTool` 输出才会创建文件。同一个有界存储也会传给
会话作用域的受管 Bash 任务；终态快照只暴露不透明 ID、状态目录下的相对路径、字节数
和是否再次截断。模型可见消息不会加入工具参数、环境变量、绝对路径或原始完整输出。
输出文件是诊断能力，写入失败采用失败开放策略：不会改变命令结果、退出码或取消语义。

既有预览、`ToolResult` 内容、事件顺序、权限检查、沙箱启动和后台任务生命周期保持不变。
文件读取器、ACP 客户端拥有的终端和自动唤醒摘要继续使用原有有界路径；将文件产物扩展
到这些来源属于另一个需要审查的切片。

## 非目标

本决策不新增 SQLite 行、会话回放/导入/导出、读取产物的新工具、跨进程任务恢复、原始
命令转录或无界捕获，也不削弱工作区/沙箱边界或通过工具元数据暴露凭据。

## 验证

定向的产物存储、前台 Bash、受管后台 Bash、后台管理器、工具流水线、架构和导入契约
测试覆盖脱敏顺序、字节上限、私有文件权限、原子创建、未注入存储时的兼容性、终态产物
元数据以及未改变的任务行为。
