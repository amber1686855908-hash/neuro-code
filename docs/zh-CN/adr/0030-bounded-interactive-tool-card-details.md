# ADR 0030 — 有界的交互式工具卡片详情

**简体中文** · [English](../../en/adr/0030-bounded-interactive-tool-card-details.md)

## 状态

已接受。

## 背景

ADR 0029 通过在一张稳定卡片中显示有界且经过脱敏的输出与工作区差异，使每次工具调用都
可以审计。这些详情很有用，但连续执行多次读取、命令或编辑时，卡片可能占据大部分终端
视口。用户需要在不丢失调用、权限路径、变更摘要、终态和耗时的前提下收起已完成的详情。

展开控件不能成为访问不受限制输出、供应商原始载荷、凭据或再次读取文件系统的通道，也
不能让一次调用重新变成多个对话条目。

## 决策

- 当存在有界详情时，运行时工具条目使用可聚焦的 `ToolFeedbackMessage`。鼠标单击、
  `Enter` 或 `Space` 会原地切换卡片；应用自有的提示与 tooltip 会随界面语言本地化。
- 卡片默认保持展开，以保留既有的可审计结果。收起时只隐藏输出正文行与统一差异片段；
  调用、权限/审批路径、输出行数、变更文件路径与增删行数、隐藏/截断提示、最终状态和耗时
  仍然可见。
- 展开不会获取更多数据。两种状态都只从同一份 `ToolFeedbackState` 渲染，并且必须已经
  经过 ANSI/控制字符清理、凭据脱敏、工作区报告过滤以及既有的 40 行/6,000 字符 TUI
  上限。载荷继续作为 Rich 字面 `Text`，不能注入样式。
- 展开状态只是表现层的进程内状态，不会写入 SQLite 会话、发送给模型，也不会把历史记录
  恢复成富工具卡片。生命周期更新、语言切换和用户切换都继续更新原调用 ID 对应的同一个
  控件，并沿用现有的滚动跟随保护。

## 后果

用户可以释放终端空间，并重新打开完全相同的安全预览，而不会改变执行、授权或审计元数据。
没有输出或差异详情的卡片不会进入键盘焦点遍历。由于应用不保留不受限制的完整记录，展开
也无法显示原安全上限之外的内容；持久化完整命令记录仍是独立的后续能力。

## 验证

Textual 测试会完成一次工具生命周期，验证默认显示经过脱敏的差异，通过键盘收起并保留文件
摘要，再用鼠标单击展开，同时确认两次渲染以及英语切换到中文后都不存在凭据。
