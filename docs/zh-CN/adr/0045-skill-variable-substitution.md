# ADR 0045：有界技能变量替换

**简体中文** · [English](../../en/adr/0045-skill-variable-substitution.md)

- 状态：已接受
- 日期：2026-07-22

## 背景

固定 Rust 基线允许已加载技能使用调用参数并引用自身目录。Neuro Code 尚无斜杠命令、
会话令牌或插件令牌界面，但这些核心替换对模型调用的技能工具有直接价值。

## 决策

为 `skill` 工具增加可选字符串 `args`，并只在加载所选正文时执行替换：

- `$ARGUMENTS` 替换为去除首尾空白后的完整参数字符串。
- `$ARGUMENTS[N]` 和 `$N` 使用从零开始、按空白分割的参数。
- `${SKILL_DIR}` 替换为所选技能目录。
- 若正文没有受支持的参数令牌且参数非空，追加 `**ARGUMENTS:** ...` 以保持兼容。

参数上限 8 KiB，单个正文最多执行 32 次受支持替换。位置参数探测使用与 Rust 兼容的
有界窗口；不支持或类似价格的 `$100`、超大数字索引及未知 `${...}` 名称保持原样。
替换使用回调函数，避免 Windows 反斜杠被当作正则替换语法。

## 影响

- 空参数或纯空白参数不会追加后缀。
- 仅路径替换不会消费参数，因此仍会收到兼容后缀。
- `${SESSION_ID}`、Claude 别名、插件根/数据、斜杠命令和插件执行仍不在范围内。
