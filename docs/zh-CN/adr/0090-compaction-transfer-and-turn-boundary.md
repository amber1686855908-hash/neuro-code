# ADR 0090：压缩条目传输与回合最终化边界

- 状态：已接受
- 日期：2026-08-08
- 范围：会话导入/导出、分叉与压缩持久化

## 背景

`DurableCompactionItem` 是用于校验和重建有界上下文投影的优化记录，
不是规范会话历史。现有会话导出格式属于公开交换数据，而
`SessionStore.finalize_turn()` 会原子提交完成事件、有序会话条目、搜索投影和可选执行记录。

## 决策

压缩行有意排除在 `SessionExport` 之外，因此不会进入 JSON/Markdown 导出或快照导入。
导入/导出只保留规范会话条目；导入后的会话不带压缩行，只有未来的显式操作才能重新构建或创建压缩行。
这样可以把摘要、不透明源指纹、Provider 亲和信息和压缩实现细节留在接口契约之外。

分叉按现有会话分叉契约复制规范会话投影，但不复制压缩行。子会话可能与父会话上下文分叉，
父会话的源指纹或 Provider 窗口不能被当作子会话的有效状态。

压缩持久化仍是独立的短存储事务。`finalize_turn()` 不会隐式保存、删除或回滚压缩行。
它的原子性声明仅限于自身的完成事件、会话条目、搜索投影和可选执行记录。
如果未来 Runtime 接入需要压缩写入与回合最终化处于同一事务，必须新增明确的存储契约和测试；
调用方不能从连续调用两个方法推断跨操作原子性。

删除继续依赖会话外键级联。没有压缩行的旧会话保持完全兼容。

## 结果

- 导出 schema 版本保持不变。
- 从导入或分叉会话恢复时只使用规范条目，不会带入父会话过期的压缩元数据。
- 当前导出路径不会渲染摘要、指纹、prompt、工具载荷或 Provider 私有元数据。
- 该边界保持行为兼容，不启用 Runtime 自动压缩，也不新增事件。
