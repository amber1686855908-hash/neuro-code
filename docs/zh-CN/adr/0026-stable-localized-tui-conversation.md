# ADR 0026 — 稳定且可本地化的 TUI 对话

**简体中文** · [English](../../en/adr/0026-stable-localized-tui-conversation.md)

## 状态

已接受。

## 背景

第一版 TUI 把已提交历史渲染到预渲染日志中，却在提示框旁的另一个组件里流式显示当前
助手回答。轮次完成时，临时组件会被移除，再向日志追加一个新条目。同一回答因此会更换
容器和屏幕位置，流式结束后产生明显跳动；窗口尺寸变化时，临时文字还可能贴近输入框。

每行重复添加 `You:` 或 `Assistant:` 也会让长对话看起来像诊断日志。此外，尽管模型和
用户内容已经支持 Unicode，应用自有文案仍固定为英语。

## 决策

- 对话记录是可滚动的纵向对话，每条可见消息对应一个稳定组件。用户提示采用占满整行的
  低对比度提示块；助手回答使用独立正文块，不再重复角色名称前缀。
- 提交提示时，在对话末尾挂载一个待完成助手组件。供应商、推理和工具通知插入该组件
  之前；文本增量与最终回答始终更新同一个组件，完成时绝不把回答复制到另一容器。
- 只有视口本来就在末尾时，流式输出才跟随到底部。用户主动向上滚动后，后续增量不会把
  视口强制拉回。
- `UiLanguage` 为应用自有的界面外壳、对话框、标签和本地状态消息提供英语与简体中文。
  `/settings`、`/setting` 和 `Ctrl+,` 打开语言选择器。对话提示、模型回答、工具载荷、
  外部错误详情、标识符及路径不会被翻译。
- `UiPreferencesStore` 是注入式持久化端口。JSON 适配器只在配置的状态目录下将所选语言
  保存到 `ui-preferences.json`。写入采用原子替换，结果文件权限仅限用户；该适配器不会
  读取或改写供应商配置与凭据。ADR 0027 随后在同一个隔离偏好文件中增加了请求的应用层
  思考强度。
- 两套语言目录必须具有相同键集合。本地条目保留翻译键和插值参数，因此切换时可以
  重新渲染应用自有历史，同时不修改用户或模型条目。

## 后果

从等待状态到完成，流式回答始终具有同一个视觉身份；输入框继续作为独立固定控件。
消息角色通过布局即可区分，无需反复显示嘈杂标签。语言选择能够跨后续启动保留，同时与
供应商路由和密钥隔离。

本决策最初不包含 Markdown、Mermaid、媒体或富工具卡片渲染。
[ADR 0027](0027-semantic-tui-and-application-reasoning-effort.md) 随后为助手文本加入安全的
语义 Markdown，[ADR 0029](0029-auditable-in-place-tool-cards.md) 随后加入有界的原地工具
卡片，[ADR 0030](0030-bounded-interactive-tool-card-details.md) 再加入有界的展开/收起
控件；Mermaid 和媒体仍是独立切片。

## 验证

交互边界与本地化 Textual 设计由 Neuro Code 自身的界面和终端行为测试验证。
