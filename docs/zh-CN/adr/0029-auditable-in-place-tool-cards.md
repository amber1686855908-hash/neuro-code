# ADR 0029 — 可审计的原地工具卡片

**简体中文** · [English](../../en/adr/0029-auditable-in-place-tool-cards.md)

## 状态

已接受。

## 背景

如果把工具生命周期中的每个事件都显示成带标签的独立行，一次调用看起来就像多次调用。
终端只显示“完成”而不显示经过限制的真实结果，也让用户无法审计读取、搜索、目录列举或
命令到底返回了什么。编辑工具可以在参数中描述目标，但 Shell 命令可能在没有任何 stdout
的情况下创建或重写文件，因而无法只靠终态结果还原其影响。

把不受限制的工具结果复制到对话记录会引入另一组问题：凭据、控制序列、超大输出、二进制
数据以及模型或命令自带的 markup 都不能控制 UI。文件变更观察器也只能是审计辅助，不能
成为新的授权或沙箱边界。

## 决策

- TUI 为每个活动调用 ID 保存一个 `ToolFeedbackState`。`TOOL_REQUESTED` 只挂载一张稳定
  卡片，后续权限、审批、开始、结果、失败和耗时事件都原地更新这张卡片。因此固定左侧
  标签栏对每次调用只显示一次“工具”，各生命周期细节作为同一正文中的子行。供应商托管
  调用采用相同身份规则，但由于供应商契约不提供结果文本，只显示生命周期数据。
- 卡片标题只包含既有的精选调用字段。本地终态事件可显示真实工具内容，但必须先清理
  ANSI/控制字符，按启发式规则和已配置值脱敏凭据，再限制显示量。TUI 最多保留 40 行、
  6,000 个字符的有界首尾预览，并明确标出省略。载荷只作为 Rich 字面 `Text` 加入，绝不
  作为 markup 解析。
- 对每个已经获得允许且带副作用的本地工具，`AgentRuntime` 会在执行前后获取当前工作区的
  有界只读快照，并随终态事件发出可 JSON 序列化的变更报告。观察器最多扫描 4,000 个文件
  和 8 MB 合格 UTF-8 文本，单文件上限为 256 KB；版本库内部、依赖/构建/缓存目录和符号
  链接会被排除。敏感文件名完全隐藏内容；二进制、过大和耗尽预算的文件只报告路径/状态。
- 快照比较报告新建、修改和删除的相对路径。合格文本使用经过凭据脱敏的统一差异；在更
  严格的 TUI 显示限制之前，每次报告最多保留 20 个变更文件，每个文件最多 240 行/
  24,000 个字符。卡片显示增删行数，对新增/删除行分别使用绿色/红色前景和不同的淡色
  背景，并明确标注所有隐藏或截断情况。
- 只有常规权限/审批通过后，才会在紧邻工具执行前开始快照。它不会授予访问权限、改变
  发送给模型的工具结果，也不会把观测到变更当作执行成功的证明。Shell 与编辑副作用仍
  必须通过既有权限、工作区和进程沙箱适配器。
- 界面语言改变时，应用自有标签会重新渲染；工具名、路径、命令、输出和差异内容绝不翻译。
- 默认智能体指引会优先使用工作区编辑工具而不是 Shell 重定向，使编辑意图更明确、更易
  审计；快照比较仍覆盖通过 Shell 创建的变更。

## 后果

读取/列举/搜索调用默认只显示一条精简动作说明，但仍保留可交互展开的有界结果；编辑工具
或 Shell 写文件则会显示文件位置和具体变化。一次调用只产生一个对话条目，不再为每个
生命周期转换重复“工具”标签。凭据和终端控制数据不会进入渲染预览；大型或敏感变更会
明确降级为元数据，而不是悄悄消失。

快照只是尽力而为的观察，并不是文件系统事务。并发的外部写入可能被归到同一执行区间；
排除或超预算路径中的变更可能只报告而不显示内容，达到扫描上限后也可能遗漏。后台命令
可以在启动调用返回后继续修改文件，因此之后的变更不会进入启动卡片。交互式展开由
[ADR 0030](0030-bounded-interactive-tool-card-details.md) 规定；持久化完整工具记录和
检查点级回滚仍属于后续纵向切片。

[ADR 0108](0108-editorial-tui-presentation.md) 后续保留本 ADR 的逐调用状态和审计边界，
但会通过一个可见活动组投影连续调用；默认摘要与详情切换由活动组而不是每个调用控件持有。

## 验证

无头运行时测试覆盖精确编辑和 Bash 创建文件报告；工作区测试覆盖新建/修改/删除检测、
忽略目录、敏感文件隐藏和凭据脱敏；Textual 测试断言整个生命周期只使用一张稳定卡片、
显示真实结果和带色差异、移除密钥，并支持从英语原地重渲染为中文。
