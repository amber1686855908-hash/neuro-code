# ADR 0042：用户级技能发现

**简体中文** · [English](../../en/adr/0042-user-level-skill-discovery.md)

- 状态：已接受
- 日期：2026-07-22

## 背景

用户需要跨工作区生效的个人技能，同时项目本地技能必须能够覆盖它们。

## 决策

为 `FilesystemSkillDiscovery` 增加可选 `user_home`。生产环境在发现时解析
`Path.home()`，并在该根下扫描相同的固定配置目录，标记为 USER 范围。解析失败时
安全跳过 USER；主目录与工作区相同时不重复扫描。

`SkillInfo.root` 记录解释其规范化相对路径时使用的已解析边界。技能工具因此针对用户
根验证 USER 文件，而不会错误地强制其位于工作区内。LOCAL 候选先处理，所以同名
项目技能总是覆盖用户技能，不受配置目录优先级影响。

## 影响

- 个人技能发现是明确且只读的；它不会把任意工作区工具访问扩大到整个主目录。
- 测试会显式提供或隔离主目录，避免开发者机器上的技能污染结果。
- 供应商默认技能拒绝列表和远程管理的用户技能仍不在范围内。
