# ADR 0013 — Neuro Code 命名空间

**简体中文** · [English](../../en/adr/0013-neuro-code-namespace.md)

## 状态

已接受。

## 背景

项目正在演进为独立的编码智能体。如果继续在 Python 导入、命令、环境变量、状态目录、
异常类型、测试和文档中保留历史引导名称，就会把最初来源永久固化为公共契约，也会给
后续功能带来命名冲突。

## 决策

统一使用一套命名空间：

- 产品名称：`Neuro Code`；
- 发行包与可执行命令：`neuro-code`；
- Python 包：`neuro_code`；
- 环境变量：`NEURO_CODE_*`；
- 用户与项目状态目录：`.neuro-code`；
- 应用预期异常根类型：`NeuroCodeError`。

不保留历史命令、导入、环境变量和状态目录别名。供应商模型必须显式配置，应用不再提供
带供应商品牌的默认模型标识。CC Switch 输入改为通过
`NEURO_CODE_CC_SWITCH_CONFIG` 显式启用，不再让自动发现依赖另一个工具面向特定供应商
的目录结构。

产品、运行时代码和普通项目文档统一使用项目自有命名空间，并将 Neuro Code 描述为独立开发。

## 影响

此次重命名会有意中断旧的本地命令、导入、环境变量和状态路径。现有数据仍可在启动前
移动到新状态目录，并同步更新配置自动化。拉取改动后需要刷新已安装的软件包元数据和
可编辑环境。后续功能由此拥有唯一且归项目所有的命名空间。
