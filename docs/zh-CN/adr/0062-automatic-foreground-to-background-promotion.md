# ADR 0062：将长时间前台 Bash 命令提升为受管后台任务

**简体中文** · [English](../../en/adr/0062-automatic-foreground-to-background-promotion.md)

- 状态：已接受
- 日期：2026-08-02

## 背景

现有受管 Bash 表面已经拥有后台进程树，但普通前台调用在工具等待预算耗尽时会终止进程树。
这使长测试、构建和服务命令无法继续，除非再次启动命令。提升必须保留唯一一次获批副作用、
会话所有者和现有沙箱边界。

## 决策

当 `BashTool` 构造时启用了后台管理，普通前台调用具有有界的前台等待预算。命令从一开始就
由会话作用域的 `BackgroundTaskManager` 启动且只启动一次，复用现有 `ProcessTree`、沙箱 Shell
启动计划、受保护环境变量剥离、输出上限和权限决策。此路径不会为管理器设置任务级截止时间：
前台预算只决定本次工具调用等待多久。

若同一任务在预算内进入终态，Bash 返回普通的有界前台结果并删除该终态记录，避免产生重复
完成提醒，也不向模型暴露任务 ID。若预算耗尽时任务仍在运行，Bash 返回其不透明任务 ID，并
附带 `status: running`、`is_background: true` 和 `promoted_from_foreground: true`。模型可使用
现有 `task_output`、`wait_tasks` 和 `kill_task` 工具；结果元数据不包含命令、cwd、环境或输出
预览。

前台等待期间取消会终止同一棵进程树，等待有界清理，删除其终态记录并传播 `CancelledError`。
启动、管理器和终态删除失败仍按错误处理，不能悄悄报告成功或留下无所有者的活进程。后台注册表的
运行中或保留任务容量不会成为普通前台 Bash 的新限制：当管理器不能接受此次启动时，Bash 会回退到
既有的有界直接前台路径。脱离受管进程树的子进程若仍持有继承的输出管道，受管捕获会在有界时间后
把该任务标为失败，不能让 `kill`、关闭或取消无限等待。显式
`is_background=true` 保留立即启动行为和既有显式任务截止时间。后台能力关闭或管理器缺失时，
继续使用原有的前台超时并终止行为。作用域关闭和应用关闭继续拥有并清理已提升任务。

## 非目标

本决策不新增完整输出文件、跨进程任务恢复、其他工具的一般超时提升或自动重新规划。不改变
Provider、Runtime/Finalizer、持久化、权限或沙箱策略，也不需要重启应用。

## 验证

针对 Bash 和后台管理器的聚焦测试覆盖单次启动提升、终态记录清理、作用域隔离、取消、显式
后台截止时间、沙箱/环境复用、输出上限、容量回退、脱离管道清理以及既有超时和关闭行为。
