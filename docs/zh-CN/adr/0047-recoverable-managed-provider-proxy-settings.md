# ADR 0047：可恢复的受管供应商代理设置

**简体中文** · [English](../../en/adr/0047-recoverable-managed-provider-proxy-settings.md)

状态：已接受

## 背景

受管供应商 profile 原本会继承环境代理行为，但 TUI 没有暴露这一选择。因此，一个有效的
DeepSeek profile 可以成功保存，却在构造供应商时因为环境中的
`ALL_PROXY=socks://...` 被拒绝。此时设置页已经关闭，顶层配置错误会结束 TUI，用户无法
在应用内修复。存储层已经支持连同凭据一起原子删除，但 TUI 没有对应入口。

## 决策

- 为所有受管供应商持久化一个 `environment`、`direct` 或 `explicit` 的用户级默认策略。
  profile 默认继承该策略，只有显式选择时才覆盖。显式策略只保存环境变量名，绝不保存解析
  后的代理 URL 或凭据。旧版环境默认 profile 会迁移为继承；`direct` 与显式策略仍保持为
  profile 级覆盖。
- 保存前复用运行时共享的 `HttpClientPolicy` 解析器。这是本地结构/依赖校验，不会访问
  模型端点。
- TUI 启动预检会在组合运行时之前校验选中的受管 profile。可恢复失败会打开聚焦的供应商
  设置页，选中对应 profile 并显示脱敏错误。显式 CLI 覆盖与非受管配置继续在 CLI 边界
  失败关闭。
- 删除受管 profile 前要求二次确认。元数据与对应凭据条目原子移除；如果仍有 profile，
  存储会选择稳定的剩余默认项。
- 提供 `socks` 软件包 extra，用于明确的 `socks5://`/`socks5h://`。继续拒绝含义不明确的
  `socks://`，不猜测协议。

## 影响

用户可以不离开 TUI 就修复继承代理错误，为所有供应商选择全局直连，或为单个供应商指定
专属代理环境变量，且受管 JSON 不会包含代理秘密。校验通过后仍保持原子保存。保存前检查
不能证明端点可达或 API 密钥有效；这些仍是请求时供应商结果。ADR 0048 增加了独立、显式
的只读连接测试，同时保持离线保存语义不变。PAC、多代理挂载和平台钥匙串存储继续作为后续工作。
