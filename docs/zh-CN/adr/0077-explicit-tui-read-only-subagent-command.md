# ADR 0077：显式 TUI 只读子代理命令

## 状态

Stage5CW 已接受。

## 背景

CLI 和 ACP 已通过同一个应用服务提供显式且有界的只读子代理入口。TUI 需要一个小型用户入口，
但不能创建第二条执行路径，也不能把界面变成自动委派器。

## 决策

在 TUI 斜杠命令中增加 `/subagent PROMPT`。该命令要求当前已有会话，并在其他回合运行时拒绝启动。
它使用组合根提供的 `ReadOnlySubagentApplicationService` 及其默认有界步骤上限，显示简短状态，
并且只渲染返回的安全响应。

该操作运行在可取消的 TUI worker 中。它不会流式转发子事件，不会把子消息或临时上下文追加到父会话，
也不会显示内部父/任务/子会话 ID。服务缺失、会话状态无效、失败和取消都会以有界 UI 状态/错误消息呈现。

## 后果

CLI、ACP 和 TUI 都是显式入口，并共享同一应用隔离与脱敏边界。仍然没有自动委派、重试、递归、并行执行、
可写工具或父上下文复用。未来只有在确认稳定用户需求后，才考虑为 TUI 命令增加显式步骤选项。
