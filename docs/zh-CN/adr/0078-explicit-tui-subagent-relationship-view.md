# ADR 0078：显式 TUI 子代理关系视图

## 状态

Stage5CX 已接受。

## 背景

应用层已经提供有界的只读 `SubagentRelationshipQueryService`. TUI 用户需要查看子代理生命周期元数据,
但不应启动子代理、重放 transcript,或从存储细节中获知实现信息.

## 决策

增加显式 `/subagents` TUI 命令. 它只查询当前会话,并渲染有界的父任务/子会话标识符、Provider/模型标签、任务状态、时间戳和能力标签.
该命令不会执行 `resume`、`fork` 或 `delete`,也不会加载子会话消息、提示词、工具参数、输出、凭据或事件.

会话缺失、服务不可用、参数非法或结果为空时失败关闭,不会启动模型回合. 该视图使用组合根注入的应用查询服务,
TUI 不会直接读取 SQLite.

## 被放弃的方案

- 从列表中自动恢复或分叉子会话会把只读视图变成执行入口.
- 渲染子会话 transcript 或提示词会绕过有界关系投影,泄露不可信或敏感数据.
- 增加第二套 TUI 专用存储查询会形成竞争的 owner.

## 影响

TUI 现在拥有安全的父子关系检查接缝. 后续恢复、分叉和删除控件必须调用既有应用生命周期服务并单独测试;
本阶段不增加这些控件、持久化或模型活动.
