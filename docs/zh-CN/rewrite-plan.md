# 重写执行计划

**简体中文** · [English](../en/rewrite-plan.md)

## 工作方法

交付单位是可测试的用户能力，而不是上游的某个 crate。每个纵向切片都从源代码证据和测试夹具出发，依次补充领域契约、应用行为、适配器、交互界面和差异测试。Understand Anything 生成的摘要可以加速代码发现，但不能替代对源代码和测试的直接阅读。

## 里程碑

### M0 — 基线与治理

- 固定源项目和分析结果的提交版本。
- 记录业务边界、架构、兼容性矩阵、来源声明、工程规则和 ADR 流程。
- 建立黄金夹具和差异测试约定。

退出条件：M1/M2 中的每项能力都有上游证据路径和明确的负责人状态。

### M1 — 可安装的工程骨架

- 产品、发行包、命令、Python 包、环境变量、状态目录和异常统一使用项目自有命名空间。
- 跨平台软件包、CLI、配置、错误体系、领域事件和端口。
- 等价的全局 `neuro`/`neuro-code` 入口、`neuro code` TUI 别名，以及默认包含 TUI 的
  普通依赖集合。
- `version`、`inspect` 和机器可读输出。
- Ruff、mypy、pytest/unittest 基础设施以及可供 CI 使用的命令。

退出条件：项目能够安装，并且同一套契约测试在所有目标平台通过。

### M2 — 无头编码代理纵向切片

- 实现命名供应商 profile、显式线路协议、可选只读 CC Switch 配置/网关兼容，并取消
  隐式云供应商默认值；有序备用 profile 按需创建，并且只允许在第一个模型事件之前
  切换。所有供应商适配器统一支持按 profile 继承环境、直连或通过安全环境变量指定代理
  的 HTTP 传输策略。
- 在统一的多提供商端口之后实现 OpenAI Chat、带可选 xAI 方言的通用 Responses、
  Anthropic 和 Gemini 流式提供商，包括经过校验的供应商原生图片投影、对不支持角色和引用的明确
  降级、有界输出 Token、思考模式工具调用轮次的持久化推理连续性，以及严格亲和的
  xAI 原生加密上下文回放。
- 代理/工具循环、结构化工具调用、取消、步数限制、输出限额、可审计的供应商尝试/选择
  事件、单次运行故障转移开关、双门禁 DeepSeek 在线回归路径，以及受控的进程树清理。
- 可选择启用的 xAI 托管网页、X 和代码解释器工具，包括避免同名冲突的协议投影、
  供应商负责的生命周期事件，以及可持久化的原生输出回放。
- 读取、列举、grep、搜索替换和 Bash 工具，受控后台命令的快照/事件驱动单任务或多任务
  等待/终止生命周期；无头
  权限策略会检查每个可安全拆分的 Shell 命令片段。
- SQLite 会话、有序消息/供应商上下文项、前缀安全恢复、稳定标题、带排序的标题/可见
  内容搜索、JSON/Markdown 导出，以及只读 Rust JSONL 会话导入和失败关闭的供应商亲和
  上下文投影。持久化 assistant 文本
  和原生项目以供应商终态输出为规范真值，流式增量继续作为 UI 表面。

退出条件：使用假提供商的端到端测试能够完成读取、编辑、执行命令和最终回复；选择性启用的在线测试可以针对已配置的提供商完成相同行为。

### M3 — 核心 TUI 与平台安全

- 基于同一事件流的 Textual UI：提示输入、原地流式更新的稳定对话块、持久化的英语/
  简体中文界面选择、首次启动与设置页多供应商管理、审批、安全 profile/会话选择、
  工作区会话搜索、会话作用域任务
  元数据/通知、更丰富的工具卡片、模型选择器和必要的斜杠命令。
- 受控进程树、会话作用域受管后台 Shell 命令、有界任意/全部多任务等待，以及明确模型
  边界的完成元数据；
  交互式 PTY 创建/输入/尺寸调整、信号、剪贴板和文件系统通知。
- `off`、`workspace`、`read-only` 和 `strict` 沙箱配置。
- 内建沙箱的会话固定持久化、启动恢复冲突检查，以及 TUI 应用内对不同 profile 会话的
  重启边界。

退出条件：交互式冒烟测试在 Linux、macOS 和 Windows 上通过，且不会残留终端状态或子进程。

### M4 — 协议与扩展能力

- Partial ACP v1 stdio 核心：已实现官方 Python SDK framing/router、
  initialize/new/list/load/delete/fork/resume/prompt/cancel/close、持久化外部到内部
  session alias、事务持久 fork/delete、回放 load 与静默 resume、工作区范围有界 cursor
  发现、有界/脱敏可见历史回放、有界 Text/ResourceLink 输入、失败关闭权限请求、标准
  事件 update、session 级并发、断连清理，以及有界且由 session 持有的 stdio MCP 工具
  server。
- 完整 ACP 一致性仍待完成：额外目录、MCP HTTP/SSE/ACP 传输与非工具 MCP 能力、客户端
  文件系统/终端方法、多媒体 prompt/历史、embedded prompt、WebSocket，以及任何明确
  声明的 `x.ai/*` 扩展。
- 已实现有界精确名称 `AGENTS.md` 继承，以及只读 LOCAL/REPO/USER 技能发现与正文加载，
  包括动态会话目标、内容变化检查和有界变量替换。远程/服务器/捆绑技能、代理配置、
  钩子和可执行插件仍待完成，其他 MCP 传输/能力也仍待完成。
- 子代理、计划模式，以及它们与公共任务生命周期的整合。

退出条件：标准 ACP 客户端通过完整一致性场景；扩展失败不会破坏主会话。当前 partial
stdio 切片尚未满足该退出条件。

### M5 — 高级能力对齐

- 记忆/压缩、LSP、工作树/检查点、网页/媒体/Mermaid/语音、遥测/更新、leader/relay 和云服务适配器。
- 完成 CLI、配置、会话、TUI、安全审计和发布来源审查。

退出条件：上游每项公开能力均达到兼容，或存在经过批准且记录清楚的有意差异。

## 变更纪律

每项能力变更都必须包含测试、兼容性状态、源代码证据和文档。源项目更新应当相对于固定提交按行为差异进行审查，绝不机械同步文件。只有在团队配置明确后才推导日历工期，但里程碑退出门槛保持不变。
